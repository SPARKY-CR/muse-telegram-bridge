# پل میوز–تلگرام

دستیار **میوز** (Muse) خودت رو از طریق یه ربات تلگرام به تلگرام وصل کن، تا از تلگرام با میوز حرف بزنی — با حافظه، فایل‌ها، هدف‌ها و ابزارهاش، نه فقط یه چت‌بات ساده.

> 🇬🇧 English version: [README.md](README.md)

## امکانات

- **میوز کامل، توی تلگرام** — میوز تو با حافظه و فایل‌هاش توی تلگرام جواب می‌ده.
- **متن، عکس، فایل** — عکس بفرست (تحلیل می‌شه)، فایل بفرست (PDF، کد، متن خونده می‌شه).
- **ویس** — ویس بفرست؛ Whisper به‌صورت محلی (خصوصی و رایگان) پیاده‌ش می‌کنه و میوز جواب می‌ده.
- **دکمه و دستور** — `/start`، `/help`، `/status`، `/schedule` و منوی دکمه‌ای.
- **جواب زنده** — جواب‌های طولانی کم‌کم توی همون پیام بزرگ می‌شن.
- **نگه‌دارنده‌ی تایپینگ** — «در حال نوشتن...» تا وقتی جواب برسه روشن می‌مونه.
- **نگهبان گیرکردن** — اگه جواب گیر کنه (مثلاً یه کارت تأیید توی اپ میوز منتظره)، ربات خبرت می‌کنه.
- **رسید خواندن 👀** — پیامت به محض اینکه گرفته بشه 👀 می‌خوره.
- **پولر خودترمیم** — فرایند سبک که وقتی ساکتی هیچ توکنی مصرف نمی‌کنه، با ضربان و راه‌اندازی خودکار.
- **خصوصی** — فقط چت تو جواب داده می‌شه؛ بقیه نادیده گرفته می‌شن. توکن توی صندوق امن میوز می‌مونه.

## نصب با یه پرامپت (به میوز بده)

نمی‌خوای قدم‌به‌قدم خودت انجام بدی؟ این پرامپت رو به میوزت بده تا همه‌ی کارها رو خودش بکنه:

```
پل میوز–تلگرام رو از این ریپو (https://github.com/<owner>/muse-telegram-bridge) برام راه بنداز تا بتونم از تلگرام باهات حرف بزنم.

۱. ساخت ربات تلگرام با @BotFather (/newbot) رو قدم‌به‌قدم بهم بگو. بعد لینک امن ورود توکن رو بهم بده — توکن رو به‌عنوان اتصال `custom.telegram` ثبت کن (هاست api.telegram.org، جایگذاری `url_path_segment:/bot{}`). هیچ‌وقت ازم نخواه توکن رو توی چت بفرستم، و هیچ‌وقت توکن رو چاپ یا لاگ نکن.
۲. ازم بخواه به ربات پیام بدم و Start رو بزنم، بعد آی‌دی عددی چتم رو از آپدیت‌های ربات بخون.
۳. پل رو راه بنداز: فایل‌ها رو سر جاشون کپی کن، state.json رو با آی‌دی چتم بنویس، و پولر رو توی پس‌زمینه روشن کن.
۴. از poller/hook-script.sh یه هوک میوز بساز (هر ۳۰ ثانیه) با دستورالعملی که توی docs/worker-prompt.md هست.
۵. یه پیام تست توی تلگرام با منوی اصلی برام بفرست و تأیید کن که پل زنده‌ست.
۶. اگه ویس خواستم، مدل محلی Whisper رو طبق README نصب کن.

قوانین: فقط آی‌دی چت من جواب داده بشه (غریبه‌ها نادیده گرفته بشن)؛ نگه‌دارنده‌ی تایپینگ و نگهبان گیرکردن روشن بمونن؛ اگه قدمی خراب شد، ساده توضیح بده چی شد و ازم چی لازم داری.
```

## چطور کار می‌کنه

```
تلگرام ──getUpdates──► poller.py ──append──► inbox.jsonl
                                                   │
                                          هوک (هر ۳۰ ثانیه)
                                                   │ پیام جدید از تو
                                                   ▼
                                   ایجنت میوز ──telegram.py──► جواب توی تلگرام
```

بدون وب‌هوک، بدون سرور عمومی، بدون تونل — پولر فقط تماس خروجی به `api.telegram.org` می‌گیره.

## نصب

۱. **ربات رو بساز:** توی تلگرام به **@BotFather** پیام بده و `/newbot` رو بفرست. توکن رو کپی کن. خودت به ربات پیام بده و Start رو بزن.
۲. **توکن رو ذخیره کن:** توی میوز، توکن رو به‌عنوان اتصال `custom.telegram` ثبت کن (توکن هیچ‌وقت توی فایل یا لاگ نمی‌ره). بیرون از میوز: متغیر `TELEGRAM_BOT_TOKEN` رو بذار.
۳. **آی‌دی چت رو پیدا کن:** یه پیام به ربات بفرست، بعد `python3 bin/telegram.py getupdates` رو اجرا کن — آی‌دی عددی توی `message.chat.id` هست.
۴. **پیکربندی:** `cp config.example.json runtime/config.json` و `chat_id` رو بذار. (آی‌دی صاحب توی `config.json` هست؛ offset پولر جداگانه توی `state.json` ذخیره می‌شه.)
۵. **پولر رو روشن کن:** `bash setup.sh`
۶. **هوک رو نصب کن:** توی میوز از `poller/hook-script.sh` یه هوک بساز (هر ۳۰ ثانیه) با دستورالعملی که توی `docs/worker-prompt.md` هست. اگه میوز بدنه‌ی هوک رو جای دیگه‌ای ذخیره می‌کنه، `BRIDGE_ROOT` رو روی ریشه‌ی ریپو تنظیم کن تا هوک `poller.py` و `scan_inbox.py` رو پیدا کنه. پوشه‌ی کاری هوک به‌صورت پیش‌فرض `$BRIDGE_ROOT/runtime` هست؛ اگه جای دیگه‌ای می‌خوای، `BRIDGE_DIR` رو تنظیم کن — همه‌ی مسیرها (inbox، seen/pending، handled.txt، دانلودها، outbox) از همون مشتق می‌شن. نشانگرهای seen/pending به‌صورت پیش‌فرض کنار inbox هستن؛ `BRIDGE_SEEN_DIR` عوضش می‌کنه. برای ارتقا از نسخه‌های قبل از v3: اگه مکان جدید نشانگر خالی باشه، هوک یک بار نشانگرهای قدیمی رو از `$HOME/hooks/state/telegram-webhook` کپی می‌کنه (`BRIDGE_LEGACY_SEEN_DIR` عوضش می‌کنه) تا پیام‌های روز قبل دوباره بیدار نشن.
۷. **ویس (اختیاری):** مدل Whisper رو محلی نصب کن (دستورات توی README انگلیسی هست).

## دستورها

| دستور | کار |
|---|---|
| `/start` | خوش‌آمد + منوی اصلی |
| `/help` | لیست دستورها |
| `/status` | سلامت پل: پولر زنده‌ست؟ آپتایم، تعداد پول، خطاها |
| `/schedule` | کلاس‌ها و برنامه‌ی مطالعه‌ی امروز |

## امنیت

- توکن توی صندوق امن میوز می‌مونه (یا متغیر محیطی) و هیچ‌وقت توی کد یا لاگ نمی‌ره.
- فقط آی‌دی چت تنظیم‌شده جواب داده می‌شه (با آی‌دی فرستنده، توی چت خصوصی).
- دانلودها فقط توی `runtime/downloads/` با اسم فایل امن انجام می‌شن؛ عکس فقط از پوشه‌های مجاز فرستاده می‌شه.
- محتوای فایل و عکس و ویس به‌عنوان داده‌ی نامطمئن در نظر گرفته می‌شه، نه دستور.
- پولر فقط تماس خروجی می‌گیره؛ هیچ پورتی باز نمی‌شه.
- ویس به‌صورت محلی با Whisper پیاده می‌شه؛ چیزی به سرویس بیرونی فرستاده نمی‌شه.
